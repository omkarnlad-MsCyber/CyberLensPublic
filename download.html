📱 CyberLens Android App

Welcome! This project includes an Android app that captures network traffic using VPN services. Since Android apps require special build tools, you'll need to build the APK on your computer or use cloud services.

⚠️ Important: Android APKs cannot be built directly on Replit due to Android SDK requirements (5-10GB download, special build tools). Follow one of the options below to get your APK.
📦Download Source Code (TAR.GZ)

🎯 Build Options (Choose One)

Option 1: Android Studio RECOMMENDED

  1. Download Android Studio (free)
  2. Click the download button above to get the source code ZIP
  3. Extract the ZIP on your computer
  4. Open Android Studio → "Open an Existing Project" → Select the CyberLens folder
  5. Wait for Gradle sync (5-10 minutes first time)
  6. Click Build → Build APK(s)
  7. Find your APK in app/build/outputs/apk/debug/app-debug.apk

Pros: Most reliable, full debugging tools, fastest after initial setup

Time: 10 minutes first build, 30 seconds after

Option 2: GitHub Actions FREE CLOUD

  1. Download the source code above
  2. Create a GitHub repository and push the code
  3. Add a GitHub Actions workflow (see HOW_TO_BUILD_APK.md included in the ZIP)
  4. Push to GitHub - the APK builds automatically in the cloud
  5. Download APK from the Actions tab

Pros: No local software needed, builds in the cloud

Time: 5-10 minutes per build

Option 3: Command Line (Linux/Mac Users)

  1. Download the source code above
  2. Install Java 17+: sudo apt install openjdk-17-jdk
  3. Install Android SDK command line tools
  4. Run: ./gradlew assembleDebug
  5. Get APK from app/build/outputs/apk/debug/

Pros: Lightweight, scriptable

Cons: Manual SDK setup required

See HOW_TO_BUILD_APK.md in the download for detailed commands.

📝 Before Building

Configure the Backend URL:

  1. Open app/src/main/java/com/example/cyberlens/ScannerClient.kt
  2. Replace the baseUrl with this Replit's URL:
object ScannerClient {
    private val retrofit = Retrofit.Builder()
        .baseUrl("https://YOUR-REPLIT-URL-HERE.repl.co/")  // ← Change this!
        .addConverterFactory(GsonConverterFactory.create())
        .build()
    val api = retrofit.create(ScannerApi::class.java)
}
